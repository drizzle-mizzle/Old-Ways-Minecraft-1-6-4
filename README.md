# W-Factory

Minecraft-сервер 1.6.4 на Spigot. Упор на градостроение и RPG-прокачку:
игроки основывают города и развивают их, растут в классах и навыках.
Войны, осады и политика нациями — не то, ради чего это собрано:
боевые механики Towny отключены в конфиге.

## Запуск

```
docker compose up -d
```

Сервер поднимется на `25565`.

```
docker compose logs -f              # лог
docker exec mc164 mc "op ВашНик"    # команда в консоль сервера
docker compose stop                 # остановка с сохранением миров
```

Вариант без Docker (Windows) — `start.bat`. Рядом с ним нужна портативная
Java 8 в папке `jre8/`; в репозиторий она не попадает, берётся с
[adoptium.net](https://adoptium.net/temurin/releases/?version=8&os=windows&arch=x64)
как JRE-zip и распаковывается под этим именем.

## Что внутри

| | |
|---|---|
| Ядро | Spigot 1.6.4-R2.1 на Java 8 |
| Города | Towny 0.88.0.0, TownyChat, Questioner |
| RPG | Heroes 1.5.5, 67 навыков, 6 классов |
| Права и экономика | zPermissions, Vault, Essentials |
| Остальное | WorldEdit, WorldGuard, NoCheatPlus, Chairs, MobHealthDisplay |

**Версии плагинов не обновлять.** Каждая подобрана под API 1.6.x; следующие
сборки этих же плагинов собраны под 1.7 и на 1.6.4 не запускаются.

## Как устроено

Образ — это релиз: ядро, плагины, эталонные конфиги. Том `/data` — состояние:
миры, города, прогресс игроков, права. Пересборка образа обновляет плагины
и не трогает нажитое.

В репозитории лежат только конфигурация, Docker-обвязка и jar-ники плагинов.
Миры, данные Towny и Heroes — нет.

## В работе

Свой лаунчер с авторизацией и скинами — заметки и решения в
[docs/launcher-wip.md](docs/launcher-wip.md). Патчер джарников, переводящий
авторизацию и скины на свои серверы, лежит в `tools/patch_jars.py`.

## Важно

`online-mode=false`, белый список выключен. Для локальной игры это нормально,
но означает, что зайти можно под любым ником, включая ник оператора. Перед тем
как публиковать сервер наружу, включите whitelist или поставьте AuthMe.

---

Репозиторий приватный: он содержит jar-ники стороннего происхождения
(Spigot, Towny, Heroes и другие), у каждого своя лицензия, и права на их
распространение здесь не подразумеваются.
